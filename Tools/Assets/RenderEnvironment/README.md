# Store-render environment

`render_nomn_store_image.py` uses the CC0 **Hanger Exterior Cloudy** environment
from Poly Haven:

<https://polyhaven.com/a/hanger_exterior_cloudy>

Download these files into `PolyHaven/` before rendering:

- `hanger_exterior_cloudy_1k.hdr` for fast previews
- `hanger_exterior_cloudy_4k.hdr` for final lighting
- `hanger_exterior_cloudy_tonemapped.jpg` for the camera background

The downloaded assets and generated preview renders are intentionally excluded
from Git. The final public image is `Store/F117A-Nighthawk-NOMM.png`.
