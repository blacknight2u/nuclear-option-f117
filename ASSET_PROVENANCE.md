# Asset provenance

The working aircraft model was imported from the locally downloaded F-117 model archives and then
substantially cleaned, split, re-rigged, textured, and adapted for Nuclear Option in Blender and
Unity. The canonical edited result is `F117_Production_Master.blend`.

The original archive's redistribution license has not been asserted in this repository. Keep this
repository private unless the original model license and every included texture's redistribution
terms have been verified. Game-owned assemblies, prefabs, and donor assets are build-time local
dependencies and are intentionally excluded from source control.
